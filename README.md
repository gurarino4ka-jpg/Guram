# ТрейдЛаб — Практика

Русскоязычный учебный симулятор сделок с виртуальным балансом. Он помогает разобраться в направлениях long/short, стоп-лоссе, тейк-профите, комиссиях и ведении журнала. Биржевых подключений и реальных денежных операций нет.

## Запуск

Нужен Node.js 22 или новее; рекомендуемая версия 24 указана в `.nvmrc`. Внешних зависимостей нет. Из корня этого репозитория:

```sh
npm ci --offline --ignore-scripts --no-audit --no-fund
PORT=3001 npm start
```

Порт 3001 позволяет запускать симулятор одновременно с академией из **Gurman**, использующей порт 3000. Без `PORT` сервер выбирает 3000. По умолчанию он слушает только локальный интерфейс; для контейнера можно указать `HOST=0.0.0.0`.

Для разработки: `PORT=3001 npm run dev`. Клиентские изменения видны после перезагрузки страницы. Проверка готовности:

```sh
curl --fail http://127.0.0.1:3001/health
```

## Учебный сценарий

1. Изучите график синтетического инструмента и доступный виртуальный баланс.
2. Выберите направление, размер позиции, уровни стоп-лосса и тейк-профита.
3. Откройте сделку. Размер ограничен доступным капиталом; кредитное плечо не используется.
4. Переключайте свечи и наблюдайте за результатом или закройте сделку вручную.
5. Разберите результат в журнале, учитывая комиссию за вход и выход.

График генерируется локально и не соответствует котировкам какого-либо реального актива. Баланс, открытая позиция и журнал сохраняются в `localStorage` текущего браузера. Синхронизации и серверной базы данных нет. Сброс тренировки удаляет локальные результаты после подтверждения.

Симуляция упрощена: нет стакана, ликвидности, кредитного плеча, финансирования short-позиций и частичного исполнения. Направление short моделируется с резервированием виртуального капитала. Если в одной свече задеты стоп и цель, приоритет получает стоп — без тиков нельзя установить реальный порядок. Результаты такой тренировки не прогнозируют результат реальной торговли.

## Проверки

```sh
npm run check
npm test
```

Встроенный тестовый раннер Node.js проверяет торговую арифметику, обработку некорректных заявок, защитные уровни и HTTP-сервер. Сборка не нужна: используются нативные ES-модули. CI запускает проверки на Node.js 22 и 24.

## Устройство

```text
public/index.html     — интерфейс терминала
public/styles.css     — адаптивные стили
public/app.mjs        — график, формы и журнал
public/domain.mjs     — генератор свечей и движок симуляции
server.mjs            — статический HTTP-сервер и /health
tests/                — автоматические проверки
```

Для статического хостинга достаточно содержимого `public`; endpoint `/health` предоставляет сервер Node.js. Секреты и аккаунты не нужны. Парный репозиторий **Gurman / ТрейдЛаб — Академия** содержит уроки, тесты и калькулятор риска. Материалы и тренажёр предназначены для обучения, не являются инвестиционной рекомендацией.
