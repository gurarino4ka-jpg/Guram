# Поиск криптосетапов на Windows

[Скачать Guram Setup Scanner 1.1.0](./Guram-Scanner-Windows-v1.1.0.zip?raw=true)

Нужен Node.js 24 LTS. Полностью распакуйте ZIP, запустите `check-scanner.cmd`, затем `start-scanner.cmd`. Инструкция находится в `START-HERE.txt` и `README-RU.md` внутри архива.

Программа автоматически находит доступные криптопары UpScale/Bookflow. На проверке 12 ноября 2026 года получены данные 103 доступных инструментов. Каталог обновляется автоматически; временно закрытые и доступные только для закрытия позиций инструменты отмечаются отдельно.

Передача новых сигналов локальному Codex настраивается через `setup-codex.cmd`; эти вызовы расходуют лимиты Codex. Пакет ищет сетапы и передаёт их на проверку. Исполнитель сделок через интерфейс демо-счёта в этот архив не включён.

В архиве нет пользовательских ключей, сессий, аккаунтов или журнала сделок. Контрольная сумма находится рядом с ZIP.
