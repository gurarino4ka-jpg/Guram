# Мониторинг котировок на Windows

Этот модуль получает реальные свечи четырёх инструментов UpScale/Bookflow и сохраняет их на вашем компьютере. Аренда сервера, платный GPT API, регистрация отдельного бота и вход в торговый аккаунт для сбора публичных данных не нужны. Отдельных библиотек устанавливать не требуется.

## Первый запуск

1. Установите **Node.js 24 LTS** для Windows с [официального сайта](https://nodejs.org/). Достаточно обычной установки; дополнительные инструменты разработки не нужны. Если Node.js уже установлен, проверить версию можно командой `node --version` в терминале. Нужна версия 24 или новее, рекомендуется 24 LTS.
2. **Полностью распакуйте ZIP** в отдельную папку, например `Документы\Guram-monitor`. Запускать файлы внутри открытого ZIP не нужно. В распакованной папке должны находиться `monitor`, `monitor.config.json` и оба файла `.cmd`.
3. Дважды нажмите **`check-monitor.cmd`**. Он выполнит один цикл получения данных и покажет результат. Дождитесь сообщения об успешном завершении. При ошибке сохраните её текст; включение непрерывного режима не исправляет ошибку подключения.
4. После успешной проверки дважды нажмите **`start-monitor.cmd`**. Оставьте открывшееся окно работающим. Для остановки нажмите **Ctrl+C**; если Windows спросит о завершении пакетного задания, подтвердите его. Не запускайте второй экземпляр одновременно.
5. Держите компьютер включённым и подключённым к интернету. Сон, гибернация, перезагрузка или закрытие окна прерывают сбор. После остановки запустите `start-monitor.cmd` снова. Автоматический запуск при включении Windows и изменение настроек сна этот пакет не выполняет.

Git, `npm install` и ключи доступа для запуска из готового ZIP не нужны. Файлы запуска автоматически переходят в свою папку, поэтому пробелы в пути допустимы. Если Windows использует корпоративный HTTP/HTTPS-прокси, наследуются обычные переменные `HTTP_PROXY`/`HTTPS_PROXY`; для Node.js включается `NODE_USE_ENV_PROXY=1`. Отключать проверку сертификатов для подключения не следует.

## Что собирается

По умолчанию модуль проверяет **BTC, ETH, SOL и ZEC** раз в **60 секунд**, сохраняя закрытые свечи **H1, M30 и M15**. Параметры находятся в `monitor.config.json`. Открытая свеча не становится подтверждённой только потому, что её цена пересекла уровень.

Источник — сама Bookflow. В метаданных инструменты обозначены как BTC/USDT, ETH/USDT, SOL/USDT и ZEC/USDT, а интерфейс и валюта расчёта используют USD. Это не независимая проверка цен Binance.

Результаты находятся в **`data\market-monitor`**:

- `journal.jsonl` — журнал событий, по одной записи на строку;
- `status.json` — состояние последней проверки;
- `state.json` — состояние для продолжения после перезапуска;
- `snapshots` — снимки свечей по инструментам и таймфреймам.

Сохраняйте эту папку между запусками. Данные могут использоваться для последующего анализа, но записи сбора свечей не являются исполненными сделками или подтверждённой прибылью. Не перемещайте и не удаляйте файлы состояния во время работы.

Во время работы создаётся `monitor.lock`, который не позволяет запустить второй экземпляр с той же папкой данных. При обычной остановке через Ctrl+C блокировка снимается. Если после аварийного завершения запуск сообщает о существующей блокировке, сначала убедитесь, что прежний монитор действительно остановлен, сохраните копию папки данных и удалите **только `monitor.lock`**. Затем повторите запуск. Файлы журнала и состояния для обхода ошибок удалять не нужно; при сообщении об их повреждении сохраните данные для разбора.

## Границы текущей версии

Модуль выполняет **сбор данных**. Он не входит в аккаунт, не выставляет заявки, SL или TP и не принимает торговые решения от имени GPT. Чтобы перейти к автоматическому демоисполнению, отдельно нужны точные правила сигналов, подтверждённый способ подключения к Bookflow, контроль установленной защиты и восстановление состояния после перезапуска.

Сбор на домашнем компьютере не означает круглосуточную доступность: программа работает только при включённом компьютере, доступном интернете и открытом окне монитора. Использование GPT API в этот модуль не входит и не оплачивается им.
